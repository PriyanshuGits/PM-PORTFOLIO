## ✨ Overview

PM Portfolio is a modern, interactive developer portfolio designed to go beyond a traditional personal website.

Built with React, Vite, GSAP, and Three.js, it combines creative development, interactive experiences, and a cinematic visual identity.

The portfolio features a dark interface with white typography and red accents, complemented by smooth animations and interactive elements.

## 🚀 Features

### Interactive Experiences
- Interactive 3D hero experience.
- Interactive 3D digital world.
- Virtual 3D developer workspace.
- Interactive morphing shape studio.
- Draggable interactive cards.
- Interactive project showcase.

### Animations & Visuals
- Animated preloader.
- GSAP-powered animations.
- Scroll-triggered reveal effects.
- Smooth transitions and hover interactions.
- Dynamic visual elements.
- Responsive interface.

### Smart Interactions
- Interactive project filters.
- Project details popup.
- Live project previews.
- Touch swipe and mouse drag navigation.
- Personalized returning-visitor experience.
- Interactive voice controls.
- Browser speech recognition and text-to-speech support.
- Interactive command terminal.

### AI Digital Twin
- Interactive portfolio assistant.
- Answers questions about my profile, projects, and technologies.
- Uses predefined local responses.

### Progressive Web App
- PWA support.
- Installable portfolio experience on supported devices.
- Automatic service worker updates.
